# azure client (beta)

a custom client for minecraft 1.21.11 (fabric), made by wysss. this is a beta, expect rough edges.

what is in it:
- custom title screen with your skin, falling stars and an animated logo
- custom loading screen, buttons, sliders and menus in a purple glass look
- the azure menu on right shift, with modules, settings and profiles, plus a drag and drop hud editor
- modules: discord presence (editable lines), server namer, tuff bright, custom inventory
- frame boost and frame trim are built in
- nuit and nuit interoperability are built in for custom skies (mit license, see `licenses`)
- window title is azure client

needs fabric api. client only. press right shift in game for the menu.

`1.21.11` has the sources, the jar is in `builds`. build with `./gradlew build`. java 21.
